# 🍔 SpamFood - Food Ordering App (UI Prototype)

**SpamFood** is a simple desktop application built with Java and Swing. 
It's not a fully functional app — think of it as a **design prototype** or a **template** for an online food ordering system.

There's no database, no backend, and nothing is actually saved permanently. 
It's all about the **look and feel** of a real food delivery app.

---

## 🤔 What is this?

This project is a **front-end prototype** for a food ordering platform. 
You can:

- Browse different restaurants
- See food items with images
- Add items to a shopping basket (locally)
- Switch between login and sign-up screens

Everything is simulated. The goal was to practice **Java Swing**, 
build a clean UI, and structure a medium-sized Java project.

## 🚀 How to Run It

### You'll need:
- Java JDK 17 or newer
- Any Java IDE (IntelliJ, Eclipse, VS Code, etc.)
- Add JavaFx into your project

### Steps:
1. Clone this repository:
   ```bash
   git clone https://github.com/0bit0uchihaa/My-Java-Project-SpamFood-Ordering-Program-.git
2. Open the project in your IDE.

3. Find Main.java inside src/SpamFood/.

4. Click Run (or press Shift + F10 in IntelliJ).

That's it! The app will open and you can start clicking around.
